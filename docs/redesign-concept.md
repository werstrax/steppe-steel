# Steppe Steel v3 — концепт «ЗАВОДСКОЙ СТАНДАРТ»

Полный редизайн на движке pro-site (BÜRO build.mjs, ноль зависимостей).
Дата: 2026-08-11. Деплой: https://werstrax.github.io/steppe-steel/ (basePath /steppe-steel).

## Идея

Сайт = завод ночью + лист КМД. Два мира чередуются по скроллу:

- **СТАЛЬ** — тёмные кинематографичные секции (#0E0F10): видео дрон-облётов,
  фирменные визуализации, гигантская типографика, зерно-шум.
- **ЛИСТ** — светлые «чертёжные» секции (#F4F2ED): линии сеток, размерные
  выноски, штампы, mono-метаданные. Инженерное ДНК из v1 («Белый чертёж»)
  живёт здесь, но теперь как контраст, а не как весь сайт.

Один акцент — фирменный оранжевый **#E8781A** (из логотипа). Дозировано:
активные состояния, цифры, штампы, линия прелоадера.

## Типографика (смелое решение)

- **Unbounded** (200–800, дисплей) — широкий техно-гротеск, перекликается
  с леттерингом логотипа. Только UPPERCASE-заголовки и огромные цифры.
  Субсеты cyrillic + cyrillic-ext + latin, self-hosted.
- **Inter** — текст (woff2 из эталона).
- **JetBrains Mono** — штампы, номера листов, размеры, координаты.
- Cormorant НЕ используем — антиква чужда заводу.

## Фирменные приёмы (переносим из v1 и усиливаем)

1. Нумерация секций «ЛИСТ 01…» — mono-лейблы + рамка листа на светлых секциях.
2. **Интерактив профилей Sigma/C/П** — живой лист КМД: SVG-сечение рисуется
   по обводке, ползунок толщины 1,5–3,5 мм утолщает металл. Главная фишка.
3. **Калькулятор зерна** (67 т/м пшеница…) и квиз-заявка с рулеткой шагов
   и штампом «В ПРОИЗВОДСТВО».
4. Координаты завода mono: «с. Троебратское · Костанайская обл.».
5. Слоган INDUSTRIAL STANDARD — в маркизе и подвале.

## Вау-слой (из эталона, дозировано под нишу)

Прелоадер-шторка (логотип-band + оранжевая линия), line-split hero-заголовка,
маркиза контурных букв (СТАЛЬ · СТЕПЬ · ЛСТК · ЧЁРНЫЙ МЕТАЛЛ), кастомный
курсор, видео-hero (hero-steppe.mp4), CSS-параллакс, живые цифры, магнитные
кнопки, view-transitions, гигантский вордмарк STEPPE в футере, полоса
«Дальше →», пейджеры соседей, перекрёстные блоки статья↔продукция,
липкий WhatsApp на мобиле. Всё гаснет при reduced-motion.
