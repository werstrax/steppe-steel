## 3. КАННИБАЛИЗАЦИЯ

| Риск | Конфликтующие страницы | Как разнести интенты |
|---|---|---|
| «ангар» vs «склад» vs «зерно» | `/resheniya/angary/` ↔ `/resheniya/sklady/` ↔ `/resheniya/zernohranilishcha/` | Ангары = универсальное быстровозводимое здание (холодное/утеплённое), слова «ангар, каркасный ангар». Склады = логистика: доки, стеллажные нагрузки, «склад, складской комплекс». Запросы «ангар для зерна / зерносклад» — только на зернохранилищах; на странице ангаров про зерно не писать, ставить ссылку |
| Сегмент vs тип здания | `/agrariyam/` ↔ зернохранилища, овощехранилища, здания для техники | «Аграриям» — B2B-страница про отрасль: боли, сезонность, кейсы, пакет «всё хозяйство от одного завода»; товарных запросов («зернохранилище цена») в Title/H1 не использовать. Товарный интент канонично живёт на страницах решений |
| ЛСТК/ЛМК ×3 | `/tekhnologii/lstk/` ↔ `/tekhnologii/lmk/` ↔ `/blog/lstk-lmk/` | Технологические страницы = коммерческий интент («производство лстк», «здания из лмк»). Блог = информационное сравнение «что лучше, отличия»; в блоге не дублировать коммерческие CTA-заголовки, дать ссылки на обе технологии |
| Регио-страницы vs главная | `/kostanay/`, `/petropavlovsk/`, `/kokshetau/` ↔ `/` | Главная держит «казахстан»-запросы; регио — только «металлоконструкции/ангар + город», уникальные блоки (доставка в регион, местные объекты, представитель). Не копировать текст главной, иначе склейка |
| Проектирование ×3 | `/proektirovshchikam/` ↔ `/tekhnologii/proektirovanie/` ↔ `/blog/km-kmd/` | Технология = услуга «проектирование металлоконструкций, разработка КМД» (коммерческий). Проектировщикам = партнёрская страница для бюро (узлы, библиотеки, сотрудничество), без запроса «проектирование металлоконструкций» в Title. Блог = справочник «что такое КМ и КМД» |
