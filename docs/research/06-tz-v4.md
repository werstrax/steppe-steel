# ТЗ v4 (30.08.2026) — разбор и решения

Заказчик жёстко раскритиковал v3 «Заводской стандарт» (тёмная тема, чертёжные
листы, ИИ-видео) и прислал полное ТЗ. Ключевая смена: бренд пишется **STEPSTEEL**,
позиционирование — «завод-изготовитель», стиль — «промышленный европейский
завод»: белый фон, графит/металл, один акцент, никакой рекламной мишуры.

## Что похоронило v3 (выводы из критики)

- ИИ-видео в hero — «все орали ужасно». ИИ-видео на сайте больше НЕ используем.
- Тёмная тема + Unbounded + оранжевые ленты = «типовой рекламный лендинг»,
  а нужен строгий корпоративный сайт производителя.
- Чертёжная игра («ЛИСТ 02», штампы на каждом блоке) — перегруз. Чертёжность
  остаётся дозированно: настоящие схемы, узлы, КМ/КМД — не декорация.
