# STEPPESTEEL — сайт завода

Корпоративный сайт завода-изготовителя строительных металлоконструкций
Steppe Steel (с. Троебратское, Узункольский район, Костанайская область,
Казахстан). Сделан по ТЗ заказчика от 30.08.2026 (`docs/TZ.md`): главная —
по структуре ТЗ §5, первый экран «Завод строительных металлоконструкций /
Проектирование. Производство. Комплектная поставка.». Статический генератор
без зависимостей — чистый Node, на выходе обычные HTML-файлы.

Все фото на сайте — реальные: съёмка объекта завода с дрона 24.09.2026
(`drone-*`) и кадры цеха из презентаций завода (`prod-*`). ИИ-изображений нет.

**Живой сайт:** https://steppesteel.kz

## Структура

```
build.mjs            сборщик: JSON-данные → HTML в dist/ (+ языковые зеркала)
src/
  data/*.json        ВЕСЬ контент сайта (правьте здесь, не в HTML)
  data/images.json   манифест картинок (пишет оптимизатор)
  data/kk/           казахская версия (появится папка — соберётся /kk/)
  pages/*.mjs        шаблоны страниц (главная — home.mjs)
  lib/               движок: layout, компоненты, schema.org, утилиты
  assets/            css, js, шрифты (self-hosted), картинки, документы PDF
    css/             site.css (система) → pro.css → experience.css → pages.css
    img/raw/         исходники картинок (в git не попадают)
    img/raw/viz-archive/  снятые кадры — в сборку не идут, обратно не возвращать
tools/
  serve.mjs          локальный сервер dist/ (порт 4321; DIST_DIR/PORT — песочница)
  check.mjs          валидатор: ссылки, SEO, JSON-LD, alt, доступность
  screenshot.mjs     скриншоты страниц (headless Chrome)
  audit_mobile.mjs   аудит переполнений на 375/360/320
  test_functional.mjs функциональные тесты форм/калькуляторов/меню
  deploy.mjs         публикация: только dist/ → отдельный dist-репозиторий
  make_og.py         OG-картинка из кадра цеха + знак + формула ТЗ
  optimize_images.py raw-исходник → WebP-набор + LQIP + запись в манифест
  slop.py            детектор словесных штампов по anti-slop-чеклисту
dist/                сборка (генерируется, в git не хранится)
docs/                ТЗ, исследования, заметки
```

## Команды

```
node build.mjs              # собрать сайт в dist/
node build.mjs --watch      # пересборка при изменениях
node tools/serve.mjs        # http://localhost:4321/
node tools/check.mjs        # проверки (0 ошибок = можно деплоить)
node tools/test_functional.mjs   # формы, калькуляторы, меню
node tools/audit_mobile.mjs      # переполнения на мобильных
python tools/slop.py src/data    # словесные штампы
python tools/optimize_images.py <имя-слота>   # ТОЛЬКО с именем, никогда --force
```

⚠️ Оптимизатор без имени обрабатывает ВСЕ файлы из `img/raw/`, а с `--force`
пересобирает манифест целиком. Поэтому только `optimize_images.py <имя>`.

## Деплой

Сайт публикуется из ОТДЕЛЬНОГО публичного dist-репозитория — в нём только
собранные HTML/CSS/JS/картинки, без исходников, документации и сырых кадров:

```
node tools/deploy.mjs --dry-run   # собрать и проверить, что в выдаче нет лишнего
node tools/deploy.mjs             # копия в клон dist-репозитория + коммит
node tools/deploy.mjs --push      # + публикация (после согласования)
```

Переключение GitHub Pages и приватность репозитория исходников — в HANDOFF.md
(раздел «Деплой»). Замена контента, фирменные правила, события аналитики,
формы — там же. Чего не хватает от заказчика — в CONTENT-TODO.md.
