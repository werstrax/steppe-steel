# STEPPESTEEL — сайт завода (v4 «Белый завод»)

Корпоративный сайт завода строительных металлоконструкций Steppe Steel
(с. Троебратское, Костанайская область, Казахстан). Сделан по ТЗ заказчика
от 30.08.2026 и правкам №1. Статический генератор без зависимостей —
чистый Node, на выходе обычные HTML-файлы.

**Живой сайт:** https://steppesteel.kz

## Структура

```
build.mjs            сборщик: JSON-данные → HTML в dist/ (+ языковые зеркала)
src/
  data/*.json        ВЕСЬ контент сайта (правьте здесь, не в HTML)
  data/kk/           казахская версия (появится папка — соберётся /kk/)
  pages/*.mjs        шаблоны страниц
  lib/               движок: layout, компоненты, schema.org, утилиты
  assets/            css, js, шрифты (self-hosted), картинки, документы PDF
    img/raw/         исходники картинок (в git не попадают)
tools/
  serve.mjs          локальный сервер dist/ (порт 4321)
  check.mjs          валидатор: ссылки, SEO, JSON-LD, alt, доступность
  screenshot.mjs     скриншоты страниц (headless Chrome)
  audit_mobile.mjs   аудит переполнений на 375/360/320
  test_functional.mjs функциональные тесты форм/калькуляторов/меню
  slop.py            детектор словесных штампов по anti-slop-чеклисту
  optimize_images.py raw-исходники → WebP-набор + LQIP + манифест
dist/                сборка (генерируется, в git не хранится)
docs/                исследования v4, заметки контент-агентов, архив v3
```

## Команды

```
node build.mjs              # собрать сайт в dist/
node build.mjs --watch      # пересборка при изменениях
node tools/serve.mjs        # http://localhost:4321/
node tools/check.mjs        # проверки (0 ошибок = можно деплоить)
node tools/test_functional.mjs   # формы, калькуляторы, меню
node tools/audit_mobile.mjs      # переполнения на мобильных
python tools/slop.py src/data    # словесные штампы
python tools/optimize_images.py  # после добавления картинок в raw/
```

## Деплой

GitHub Pages отдаёт корень ветки `main`:

1. `node build.mjs` и `node tools/check.mjs` — ошибок нет.
2. Скопировать содержимое `dist/` в корень репозитория.
3. Commit + push в `main`.

Подробности, замена контента, события аналитики и подключение форм —
в HANDOFF.md. Чего не хватает от заказчика — в CONTENT-TODO.md.
Открытые решения (приём файлов заявки, CMS) — там же, ждут выбора варианта.
