## 2. Стек и как всё устроено

Ванильный статический генератор, **зависимостей нет**, `npm install` не нужен.

```
build.mjs              сборщик: собирает dist/ из данных и шаблонов
src/data/*.json        ВЕСЬ контент (17 файлов). HTML руками не пишется
src/pages/*.mjs        шаблоны страниц (16 файлов)
src/lib/
  layout.mjs           <head>, шапка, подвал, микроразметка, счётчики
  components.mjs       переиспользуемые блоки (логотип, карточки, карта, формы)
  schema.mjs           JSON-LD (Organization, WebSite, Product, FAQ, HowTo)
  util.mjs             html/raw-шаблоны, picture(), hasImage(), escaping
src/assets/css/site.css      дизайн-система варианта А (18 разделов)
src/assets/css/theme-tz.css  тема варианта Б поверх site.css
src/assets/js/site.js        меню, формы, калькуляторы, аккордеоны, аналитика
src/assets/img/raw/          исходники картинок (в сборку НЕ идут)
src/assets/img/              оптимизированные WebP/JPEG (идут в dist)
tools/                       проверки и утилиты (см. §7)
docs/                        ТЗ, аудит, исследования
```

Шаблоны — теговые функции `html` и `raw` из `util.mjs`, не JSX. Данные с
префиксом `_` (например `_note`, `_readme`) — служебные заметки, сборщик их
выбрасывает; в них хранятся источники цифр, не удаляй.

Картинки: `picture('имя-слота')` берёт запись из `src/data/images.json`.
Если записи нет — `hasImage()` вернёт false и на странице встанет честная
плашка `photoSlot()`. Поэтому «нет фото» никогда не ломает вёрстку.

### Команды

```bash
node build.mjs                       # обычная сборка в dist/
VARIANT=tz node build.mjs            # сборка варианта Б (см. §4)
node tools/check.mjs                 # ссылки, SEO-длины, JSON-LD, alt — должно быть 0 ошибок
node tools/test_functional.mjs       # 52 CDP-теста (нужен запущенный сервер)
node tools/audit_mobile.mjs          # переполнения на 375/360/320 (нужен сервер)
node tools/screenshot.mjs            # скриншоты всех страниц в screenshots/
node tools/screenshot.mjs --mobile / # только главная, 375px
python tools/optimize_images.py имя  # обработать raw/имя.* → WebP-набор + манифест
python tools/slop.py src/data        # словесные штампы
```

**Локальный сервер обязателен для тестов и аудита.** Без него они проходят
вхолостую и печатают «ok» на пустом месте. Запускать только отдельным
процессом — фоновая задача Bash умирает между ходами:

```powershell
Start-Process node -ArgumentList "tools/serve.mjs" -WindowStyle Hidden -WorkingDirectory "C:\Users\Flockyman\Desktop\stepee steel site"
```

Порт 4321. Проверка: `curl -s -o /dev/null -w "%{http_code}" http://localhost:4321/`.

- **А:** фото цеха во всю ширину на первом экране, цифры-манифест крупно,

## 5. Деплой — здесь была дорогая ошибка

**Слово «деплой» без явного «на домен» означает ПРЕВЬЮ.** 02.09 версия была
выкачена на боевой домен без спроса, реакция была резкой. На домене должна
стоять заглушка, пока заказчик не одобрит.

```bash
# Вариант А → превью
PREVIEW=1 SITE_URL=https://werstrax.github.io/steppesteel-preview \
  BASE_PATH=steppesteel-preview node build.mjs
# содержимое dist/ скопировать в /tmp/ssprev (репо werstrax/steppesteel-preview), push

# Вариант Б → своё превью
VARIANT=tz PREVIEW=1 SITE_URL=https://werstrax.github.io/steppesteel-tz \
  BASE_PATH=steppesteel-tz node build.mjs
# содержимое dist/ скопировать в /tmp/sstz (репо werstrax/steppesteel-tz), push
```

`PREVIEW=1` даёт noindex на всех страницах, `Disallow` в robots.txt и не
копирует CNAME (иначе GitHub отвяжет домен).

⚠️ **BASE_PATH передавать БЕЗ ведущего слэша.** Git Bash на Windows
подменяет `/steppesteel-preview` на `C:/Program Files/Git/steppesteel-preview`,
и превью открывается без стилей. В `build.mjs` есть `normalizeBase()`,
который берёт последний сегмент пути и чинит оба случая.

Коммиты в превью-репозиториях делать с явной подписью:
`git -c user.name=werstrax -c user.email=ramazan.ship@gmail.com commit`.
Плюс `-c core.safecrlf=false`, иначе Windows завалит вывод предупреждениями.

## 6. Правила контента — нарушение стоит доверия заказчика

Реестр проверенных фактов и полный список запретов: `docs/research/v4/01-fakty.md`.
Главное:

1. **Только проверяемые цифры.** Каждая цифра на сайте имеет источник в
   `_note` рядом с ней. Нет источника — цифры на сайте нет.
2. **Никаких выдуманных объектов, отзывов, цен, счётчиков «N объектов сдано».**
3. **Пролёт — только «до 24 м».** В презентации партнёрской сети есть «до 30 м»,
   конструктор это не подтвердил. Не «чинить» на 30.
4. **Цифры из макета Шамиля** (7 000 м², 700 т/мес, 10 представителей,
   30 дней) на сайте отсутствуют — макет сгенерирован, цифры не подтверждены
   документами. Ждут письменного подтверждения.
5. **Фото — только материалы завода.** ИИ-визуализации сняты решением
   Рамазана; всё, что стоит сейчас, вытащено из двух презентаций завода
   (`src/assets/docs/*.pdf`). Архив снятых ИИ-кадров —
   `src/assets/img/raw/viz-archive/`, обратно не возвращать.
6. **Профили называются ПСУ и ПС.** ПСУ — С-образный усиленный (сигма),
   ПС — С-образный. П-профиль завод не катает, его на сайте нет. Числа
   сортамента берутся только из таблиц конструктора (`profiles.json`).
7. **«Троебратское»** — село (не «Троебратное», это озеро). Но в юридических
   документах строка «с. Троебратное» — её не исправлять.
8. Бренд пишется **STEPPESTEEL** (в прозе Steppe Steel). Написание STEPSTEEL
   из ТЗ — опечатка заказчика, обратно не «чинить»; оно оставлено только
   в `alternateName` микроразметки.

## 10. Грабли — на них уже наступали

- **Оптимизатор картинок.** В `raw/` под одним именем должен лежать ОДИН файл.
  Когда там оказались и `x.jpg`, и `x.png`, скрипт взял старый jpg — и на
  «сайте без ИИ» полдня стояли ИИ-кадры. Флаг `--force` со списком имён
  **пересоздаёт манифест только из этих имён**, остальные записи пропадают:
  для замены одного кадра удали `src/assets/img/<имя>-*` и запусти без `--force`.
- **Тесты без сервера** молча проходят вхолостую.
- **Фоновый сервер в Bash умирает** между ходами (код 4) — только Start-Process.
- **CSS-специфичность:** `.header__cta { display: none }` в медиазапросе
  перебивался поздним `.btn { display: inline-flex }` равной специфичности.
  В медиазапросах писать `.header .header__cta`.
- **Переполнение одного элемента** в мобильной эмуляции раздувает viewport,
  и всё меряется шире. Искать виновника, пряча подозреваемых по одному.
- **`hyphens: auto` на крупном H1** рвёт «метал-локонструкций» на десктопе.
  На больших кеглях — `hyphens: manual` плюс `&shy;` в нужном месте, `auto`
  включать только на мобильном.
- **Поле формы `length`:** `form.elements.length` — это число элементов,
  а не поле. Поле длины здания называется `len`.
- **Heredoc в Bash** ломается на кавычках в русских строках — многострочные
  патчи писать файлом и запускать `node файл.mjs`.
