## 3. Стек и устройство

Ванильный статический генератор, **зависимостей нет**, `npm install` не нужен.
Node 20+, Python 3 (Pillow, PyMuPDF) для картинок и PDF, ffmpeg для видео.

src/lib/

  components.mjs       блоки: logo(), pageHero(), brandTag(), factoryBand(), карта, формы…
  icons.mjs            линейные иконки главной (показатели, шаги)
  experience.mjs       полка документов на главной
  schema.mjs           JSON-LD
  util.mjs             html/raw, picture(), hasImage(), typo-обработка
src/assets/css/        site.css (система) → pro.css (главная) → experience.css → pages.css
src/assets/js/site.js  меню, форма, калькуляторы, лента, видео первого экрана, аналитика
src/assets/img/raw/    исходники картинок (в git НЕ идут, папка в .gitignore)

## 6. Деплой

**Правило:** слово «деплой» без явного «на домен» = ПРЕВЬЮ. 02.09 версия ушла
на домен без спроса — реакция была резкой. Боевой домен обновлять, когда
пользователь просит правку на живом сайте или говорит «на домен».

**Боевой сайт (пока на GitHub Pages, ветка gh-pages):**

```bash
node build.mjs && node tools/check.mjs                     # production: url steppesteel.kz, CNAME в dist
git clone --depth 1 -b gh-pages https://github.com/werstrax/steppe-steel.git <клон>
# в клоне: удалить всё, кроме .git; скопировать содержимое dist/ (вместе с CNAME и .nojekyll)
git -c user.name=werstrax -c user.email=ramazan.ship@gmail.com -c core.safecrlf=false commit -am "..."
git push origin gh-pages
gh api repos/werstrax/steppe-steel/pages/builds/latest --jq .status   # ждать «built»
```

CDN GitHub кэширует страницы до 10 минут. Если после смены источника Pages
сборка не стартовала — `gh api -X POST repos/werstrax/steppe-steel/pages/builds`.
Проверка: `https://steppesteel.kz/HANDOFF.md` и `/docs/TZ.md` должны отдавать **404**.
После переезда на казахстанский хостинг деплой = залить `dist/` туда (см. HANDOFF).

**Превью:**

```bash
PREVIEW=1 SITE_URL=https://werstrax.github.io/steppesteel-preview BASE_PATH=steppesteel-preview DIST_DIR=<папка> node build.mjs
# содержимое папки → клон werstrax/steppesteel-preview (ветка main) → commit → push
```

`BASE_PATH` — **без ведущего слэша** (Git Bash превращает `/x` в `C:/Program Files/Git/x`).
`PREVIEW=1` даёт noindex и не кладёт CNAME. Сборку превью делать в отдельную
`DIST_DIR`, чтобы не затереть боевой `dist/`. Клон превью раньше жил в `/tmp/ssprev`;
его `.git` однажды оказался испорчен — если `git status` падает, склонируй заново.

Коммиты — с явной подписью (`-c user.name=werstrax -c user.email=ramazan.ship@gmail.com`)
и `-c core.safecrlf=false`.

## 7. Правила контента — нарушение стоит доверия заказчика

1. **Ни одной ИИ-картинки на сайте** (требование к запуску 25.09: «без ИИшных картинок»).
   Все сгенерированные кадры сняты в `src/assets/img/raw/viz-archive/`, обратно
   не возвращать. Если пользователь присылает картинку, похожую на генерацию
   (идеальные одинаковые объекты, нет EXIF, размеры 1168×667/1536×1024 как у
   ChatGPT) — скажи прямо и спроси, реальная ли она. Так было с `obj-ovoshch-1`:
   Рамазан ответил «реальное», кадр поставлен с нейтральной подписью.
2. **Фото конкурентов не брать ни в каком виде** — ни как есть, ни «переделать
   нейросетью» (МИРКОН/vseangari.ru, lstkclub.ru, «Фабрика каркасов»). Рамазан
   просил несколько раз — отказано окончательно, не возвращаться к спору.
3. **Свободные стоки (Pexels, лицензия на коммерческое использование) — можно**,
   с 28.09 по разрешению Рамазана, только там, где нет своего кадра, и с честной
   подписью «Пример: …» (не «объект завода»). Реестр — `docs/stock-photos.md`.
   Сток **нельзя** на `/proizvodstvo/` и в «О заводе»: чужой цех на странице
   «наше производство» — обман. Касок со стоков нет (ТЗ §3).
4. **Только проверяемые цифры** — источник в `_note` или в реестре фактов.
   Цифры из макета Шамиля (7 000 м², 700 т/мес, 10 представителей, 30 дней)
   **не подтверждены** — не ставить, пока завод не подтвердит.
5. **Регион объекта со съёмки дрона не подтверждён** — не писать, где он.
   «Костанайская область» — только в адресе завода.
6. **Пролёт — «до 24 м»** (в старой партнёрской презентации «до 30 м» — не подтверждено).
7. **Цены не публикуются** (ТЗ §19).
8. **Монтаж** — единая формула до ответа Шамиля: «бригадой завода или вашей
   бригадой под шеф-монтажом инженера завода; вариант фиксируем в договоре».
9. **Бренд:** STEPPESTEEL в вордмарке, Steppe Steel в тексте; STEPSTEEL из ТЗ —

11. **Технология завода — рамы из профилей ПСУ/ПС** (как на съёмке с дрона).

## 11. Грабли

- **CRLF и смешанные переводы строк** в файлах от Codex: многострочные замены
  node/python-скриптом промахиваются. Правь инструментом Edit или проверяй оба
  варианта (`\n` и `\r\n`). Bash heredoc ломается на кавычках в русском тексте —
  скрипты писать файлом.
- **Оптимизатор картинок:** запускать только с именем слота, **никогда `--force`**
  (пересоздаёт манифест только из переданных имён). Под одним именем в `raw/` —
  один файл. Чтобы заменить кадр — удалить `src/assets/img/<слот>-*`, затем
  `optimize_images.py <слот>`.
- **Git Bash портит аргументы с ведущим `/`** (`/Фото` → `C:/Program Files/Git/Фото`):
  ставь `MSYS_NO_PATHCONV=1` или передавай без слэша.
- **Тесты без сервера** молча зелёные. Сервер — только `Start-Process`.
- **Яндекс Диск:** папку не качать zip-ом из браузера (архив собирается на лету,
  размер неизвестен, на диске C ≈ 25–30 ГБ свободно).
- **Claude in Chrome:** в браузере Рамазана аккаунт Яндекса Шамиля просит
  «обновить аккаунт» — не трогать, просить публичную ссылку.
- **Скачивание и запуск .exe из интернета** блокирует система разрешений — не обходить.
- **Проверка команд (классификатор) иногда даёт сбой** — повторить позже,
  продолжить другим.
